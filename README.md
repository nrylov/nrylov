# Hi, I'm Nikolai Rylov

I build agent tooling and preserve old software. Interests: AI coding agents, retro computing, computer history.

## AI and agent projects

| Project | What it is |
|---|---|
| [hermes-workflows](https://github.com/nrylov/hermes-workflows) | Reusable Hermes Agent skills with tested helper scripts: scheduled feed digests, evidence-graded audits, PR triage. |
| [agentberth](https://github.com/nrylov/agentberth) | A place to dock, equip, and launch agents. Tool-equipped agents behind an API, with isolated runs (Docker or Kubernetes). |
| [grok_rc](https://github.com/nrylov/grok_rc) | Remote control for the Grok CLI from a phone or browser. The agent keeps running on your machine. |
| [rs2011-ts](https://github.com/nrylov/rs2011-ts) | TypeScript implementation of the 634 RuneScape client, with an SDK for agentic interaction. |
| [code_review](https://github.com/nrylov/code_review) | Reusable GitHub Actions workflows: lint, tests and AI code review on every PR. |
